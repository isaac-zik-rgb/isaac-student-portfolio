## About the Project

The Student Portfolio and Academic Management Website is a responsive web application developed as part of the COS 106 – Introduction to Web Technologies term project at MIVA Open University.

The project is designed to provide a personal online portfolio where visitors can learn about the student, explore selected projects, view academic and professional interests, and access a downloadable CV.

It also includes an interactive Academic Planner that allows students to organise their academic activities and track task completion.

The website was developed using fundamental web technologies: HTML5, CSS3, and JavaScript.

## Features

### 1. Home Page
- Personal introduction and welcome section.
- Student profile image and navigation menu.
- Brief biography.
- Links to other sections of the website.
- Downloadable CV.

### 2. About Me
- Personal biography.
- Educational background.
- Career aspirations.
- Technical skills and interests.
- Video and audio introduction.

### 3. Projects Portfolio
- Displays selected academic and personal projects.
- Project descriptions and technology information.
- Project screenshots and navigation links.
- Downloadable CV for visitors.

### 4. Academic Planner
- Add academic tasks.
- Mark tasks as completed.
- Undo completed tasks.
- Delete tasks.
- Automatically update total, completed, and pending task statistics.

### 5. Contact Page
- Contact form with name, email, phone number, and message fields.
- JavaScript form validation.
- Email format validation.
- Phone number validation.
- User-friendly validation feedback.

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/isaac-student-portfolio.git
```

2. Navigate into the project directory:

```bash
cd isaac-student-portfolio
```

3. Open the project in Visual Studio Code.

4. Open `index.html` using a browser or the VS Code Live Server extension.

No additional dependencies or package installations are required.
